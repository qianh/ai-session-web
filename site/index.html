BrainHub

BrainHub 是一组本地优先的开源归档工具，把网页与命令行里的 AI 会话保存到你自己的 Google Drive。没有 BrainHub 云端账号，没有中转采集服务器，也不把你的内容用于广告或模型训练。

查看 Capture 源码 查看 MCP 源码

两个组件，独立安装

Capture 与 MCP 不互相依赖。它们只通过用户选择的同一个 Google Drive 根目录协作，升级或卸载组件不会删除 Drive 内容。

01

BrainHub Capture

Google Chrome 扩展。用户逐站授权后，将 ChatGPT、Claude、Gemini 和 Grok 会话，以及主动选择的普通网页文本写入自己的 Drive。 brain-hub/inbox/ · brain-hub/highlights/

02

BrainHub MCP

macOS 本地 MCP 服务。上传 Claude Code、Codex CLI 和 Grok Build 顶层会话，提供本地语义搜索、完整会话读取和数字画像读取。 Digital_Twin_Profile.md · local SQLite index

BrainHub 如何使用 Google Drive

BrainHub 请求 Google Drive 权限的唯一目的，是执行用户主动启用的归档、搜索和画像读取功能。Google 用户数据不会被发送到 BrainHub 维护者控制的服务器。

Capture 写入

BrainHub Capture 使用 drive.file，只创建和更新它自己创建或用户明确授权的归档文件。

MCP 归档与读取

BrainHub MCP 上传用户选择的 CLI 会话，并从用户自己的 Drive 读取 Digital_Twin_Profile.md 和 BrainHub 归档内容。

用户始终控制

授权可以随时撤销；升级或卸载不会删除 Drive 内容。详细的数据处理方式见隐私政策。

清楚的数据边界

BrainHub 的维护者无法访问用户的 Google Drive。授权、内容和本地索引始终由用户自己的账号与设备控制。

用户拥有

会话、精华与画像文件保存在用户自己的 Drive 或本地 Obsidian 中。

本地处理

脱敏、文本分块、向量索引和语义搜索在用户设备上完成。

无内容中转

产品没有接收会话正文的 BrainHub 服务器，不包含广告、遥测或远程可执行代码。
