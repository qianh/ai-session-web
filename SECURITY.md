# Security Policy

## Supported versions

Only the latest Chrome Web Store version of BrainHub Capture receives security fixes.

## Reporting a vulnerability

Use the repository's private GitHub Security Advisory form. Do not open a public issue for OAuth token exposure, permission bypasses, session disclosure, or Drive authorization problems.

Never attach OAuth tokens, cookies, raw conversations, private Drive file IDs, or unredacted browser profiles. Include a minimal reproduction with synthetic data and the affected extension version.
