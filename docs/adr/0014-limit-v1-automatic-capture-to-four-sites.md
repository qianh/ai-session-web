# Limit v1 automatic capture to four sites

BrainHub Capture v1 officially supports automatic AI-session capture for ChatGPT, Claude, Gemini, and Grok. Each site has an explicit adapter, optional origin permission, backfill behavior, and regression coverage. Arbitrary webpages remain eligible only for user-initiated selected-text capture; the extension does not claim a generic automatic scraper for untested AI sites.
